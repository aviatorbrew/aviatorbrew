# Sitemap

## Primary pages

- `/` — Home
- `/beer` — Our Beer
- `/beer/[slug]` — Beer detail
- `/locations` — Locations overview
- `/locations/[slug]` — Individual location pages
- `/menus` — Food + Menus
- `/events` — Events calendar
- `/events/[slug]` — Event detail
- `/private-events` — Private events inquiry
- `/brewery` — Brewery
- `/distillery` — Distillery
- `/about` — About Aviator
- `/careers` — Careers interest form
- `/contact` — Contact form
- `/shop` — Gift cards + merchandise
- `/faq` — Frequently asked questions

`src/app/sitemap.ts` emits every static route, beer, location, and event URL to `/sitemap.xml`.
