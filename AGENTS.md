# Repository Context

This repository is the Aviator Brewing Company website.

- Stack: Next.js 15, React 19, TypeScript, and Tailwind CSS
- Primary app root: this directory
- GitHub remote: `aviatorbrew/aviatorbrew`
- Purpose: public Aviator Brewing Company website with manager/admin features for menus, beers, events, coupons, tours, kegs, shop content, and related operations

After completing requested changes, commit and push to GitHub repository `aviatorbrew/aviatorbrew` unless the user explicitly asks for local-only work or the change is not ready to publish. Do not include unrelated local changes in those commits.
