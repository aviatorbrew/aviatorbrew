# À la carte event menus in the manager portal

In Private Events → Current event → Menu & Pricing, choose **À la carte menu — no buffet package** or add an item with the **À la carte menu builder**. The full current event catalog is available: regular/premium appetizers and entrées, sides, salads, pizzas, dessert display and coffee service, including manager-only selections. Unavailable items remain visible but cannot be added. Filter by category or search by name.

Set the billing unit (guest serving, individual portion, full tray, piece or whole pizza) and quantity. Automatic selling prices use internal estimated food cost ÷ 28%, rounded up to the next cent. Serving defaults are 3 oz appetizers, 8 oz other entrées (BBQ 10.4 oz; brisket 8 oz), 8 oz sides and 2 oz salads; full trays use measured or labeled estimated weights. Override the portion or selling price as needed; **Use 28% price** restores the current suggestion. Missing costs or conversions require a manual price. Pizza pricing covers rounded whole pizzas for the entered quantity. Duplicate choices can be separate lines. Off-menu dishes use **+ Add order item**.

Items are ordinary custom Food or Drinks rows in **Order summary & custom charges**, with their billing unit in the name. Quantities and prices stay fixed when guest count or menu configuration changes. With no buffet package, adding an item sets the service plan to à la carte without a buffet base charge or buffet guest minimum. If a buffet package is selected, these are additional charges and the package stays selected. Saved proposals remain frozen; save edits and create a revised proposal before obtaining new acceptance.

Kitchen sheets retain food quantities and preparation notes. Internal food-cost estimates use known matching costs where quantities support the cost basis, and mark unmatched/unverified costs incomplete. Saving and printing send no email; proposal emailing still requires explicit approval.

Validation: `npm run test:event-plans`, `npm run test:event-food-cost`, `npm run test:event-production`, and `npm run test:event-editor-ui` with mocked APIs.


The kitchen sheet shows full, half and partial trays for each weighed dish. Main proteins and plain meat/seafood appetizers share a guest-count-plus-10% serving budget; repeated choices do not multiply servings. Split evenly by default, or edit each protein’s relative share in the event’s Kitchen serving plan. BBQ defaults to 0.65 cooked lb per serving, brisket to 0.5 lb and other proteins to 0.5 lb; portion overrides are available. Wings use 5 pieces per allocated protein serving (not every guest when several proteins share the meal). Full wing trays hold approximately 200 pieces; half trays start at an explicitly unverified 75-piece estimate and can be overridden. Cooked pieces per pound is required for count-to-weight conversion. Mixed protein appetizers require recipe review before the protein total can be considered complete.

Sides and salads receive 15% extra by default, editable globally or per event. Appetizers and pizza retain their own reserve. Do not add another reserve to the protein allowance. Explicit protein orders reserve servings first; excess or unknown quantities are flagged for review rather than silently changing a customer’s order. Kitchen-only shares/portion/reserve adjustments do not invalidate customer proposal links and are excluded from customer proposal snapshots.

Selecting any pizza option opens a shared style picker (one to three varieties). Add one Pizza Bar line for the group. Adding styles splits the same total slice allowance, not an additional allowance or charge for each style. **Update pizza selection** replaces matching existing style rows with the reviewed shared order. The 28% price suggestion costs the actual rounded whole pizzas across the chosen styles.
