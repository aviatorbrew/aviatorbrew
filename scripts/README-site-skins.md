# Public website skins

Manager Portal → Marketing → Website Skins (`/manager/site-skins`) controls the single existing `website.settings` record keyed `site_theme`. No new tables or second admin system. Development without a database uses `SITE_THEME_DATA_FILE` or `data/site-theme.json` (ignored by Git).

Available skins: Standard Aviator (off), Grateful Dead Night, Holiday Gathering, After Dark. Promotion fields are shared and editable; update the event, text, image and expiration when reusing a skin. Turning off preserves those fields. The default is off. Activation is an explicit manager save, not a code-deploy side effect.

The launch promotion is Bring Out Yer Dead, November 7, 2026, 4–7 p.m. Eastern, at Aviator Amphitheater; open at 11 a.m. for pre-gaming. The original poster was copied without image edits from Aviator Live's published November 7 schedule, booking `73217e91-5438-44eb-a8a2-c46cbf00281a`. Source: `https://aviatorlive.beer/api/social/images/aadc2e3a-ad02-46ce-a41b-fa88718540c5.jpg`. Local asset: `public/images/promotions/bring-out-yer-dead-nov7.jpg`. CSS displays the portrait artwork without the original square image's side margins; no text is cut off. The local copy does not depend on the other site's image endpoint staying available.

Default expiry is November 8, 2026, at midnight Eastern (`2026-11-08T05:00:00Z`). Expiration is checked on the server and in the browser; an open page restores its ordinary hero and removes the ribbon when the time arrives. No cron job or deployment is required. Staff can clear expiration for a manually controlled skin or use Turn off skin now. An expired skin cannot be newly activated without updating/clearing the expiration.

The public layout gets cached settings (30-second server cache, invalidated on save). The presentation component refreshes on mount, window focus and each minute, so already-open pages pick up changes. The homepage's ordinary content remains available as the fallback. All theme CSS is scoped under `data-site-skin`; the default skin restores the original styles. Manager, proposal, private-event, feast and cart/checkout flows use the standard presentation. Skins do not modify navigation destinations, event records, menu data, prices, orders, customer details, proposals or payments.

`GET /api/site-theme` exposes only the public promotion settings with no-store. Manager GET/PATCH require the existing manager session and are private/no-store. Inputs are bounded plain text, validated dates/times, known skin identifiers, internal or HTTPS links; client-supplied timestamps are replaced on save. No remote content is fetched from submitted image URLs on the server.

Validation: `npm run test:site-skins` exercises expiry boundaries, labels, protected paths, input validation, storage adapters, manager authorization and cache invalidation. `npm run test:site-skins-ui` uses the real local standalone server, a disposable local database (`SITE_SKIN_TEST_DATABASE_URL`) and test-only manager session. It checks the poster, mobile navigation, desktop/tablet/mobile overflow, skin changes, off/restore and open-page expiry. Non-setting mutations are intercepted; no real customer mail, payments or records are touched. Set `AVIATOR_PLAYWRIGHT_MODULE` if Playwright lives outside this app.

## Facebook and social previews

Homepage metadata is generated on the server from the same saved skin. While an unexpired skin with artwork is active, Open Graph and Twitter metadata point to its original poster with the show name, date/time and opening message. Homepage share URLs use the primary `https://aviatorbrew.com` domain. The image URL is absolute and versioned with the saved update time; the bundled November 7 poster declares its actual 1080×1080 JPEG dimensions. Turning the skin off, expiration or missing artwork restores the regular logo and site description for new scrapes. Facebook maintains its own cached previews: use its Sharing Debugger with `https://aviatorbrew.com/` and Scrape Again if an existing preview still shows the old image. This does not publish a Facebook post.
